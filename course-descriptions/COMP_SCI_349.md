Machine learning is the study of programs that improve with experience. This is an overview of the fundamentals: classification, regression, training a model, and evaluating it, across several families of algorithms. You will see the ideas both intuitively and mathematically, and you will practice telling when a method fits a problem and then applying or implementing it. For Computer Science students, the course satisfies the AI breadth requirement.

REFERENCE TEXTBOOKS: Selected papers from journals and conferences presenting research on machine learning. Readings are provided online.

COURSE GOALS: You should leave with a working set of machine learning methods you can use on new problems, and with enough judgment to decide which method fits. That includes algorithms, optimization, and evaluation metrics, and the mathematical ideas underneath them.

DETAILED COURSE TOPICS:

The Computer Science page gives this as an example list. The exact subset changes by year.

* Decision tree learning
* Nonlinear regression
* Artificial neural networks
* Evaluating hypotheses
* Bayesian learning
* Computational learning theory
* Instance-based learning
* Genetic algorithms
* Learning sets of rules
* Reinforcement learning
* Clustering

The MSAI description organizes the same material as classification, regression, model training, and evaluation.

WHO SHOULD TAKE THIS COURSE: Take it if you want a first course in how learning algorithms work, not only how to call a library. Undergraduates need data structures (COMP_SCI 208 or 214), linear algebra (MATH 240, GEN_ENG 205-1, or GEN_ENG 206-1), and probability or statistics (IEMS 201, IEMS 303, ELEC_ENG 302, GEN_ENG 241, STAT 210, or MATH 310-1). STAT 304 does not replace COMP_SCI 208 or 214. It is also open to students in the MS in Computer Science and to doctoral students in Computer Science, Computer Science and Learning Sciences, or Technology and Social Behavior. For MSAI students it is a core course.

HOMEWORK ASSIGNMENTS: Readings from the machine learning literature, problem sets, and coding assignments in which you implement algorithms and test them on real data. The MSAI section describes these as a limited number of assignments, some coding and some written answers, plus a final group project.

LAB ASSIGNMENTS: The Computer Science page describes several labs. You implement learning algorithms and measure how they do on example data. Examples include feed-forward multilayer neural networks, decision trees, hidden Markov models, and clustering. The MSAI page does not list separate labs.

EXAMS: None described on either page.

GRADING: On the Computer Science page, grades come from problem sets, reading assignments, and programming assignments. No percentages are given. The MSAI page does not give a grading breakdown. Its work is the homework plus the final group project.
