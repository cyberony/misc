# Misc – Workspace memory

- **PDF extraction**: `extract-pdf-text.js` + `pdf-parse@1.1.1`. Run: `node extract-pdf-text.js <path-to-pdf>`. Output goes to `_extracted.txt` in the same directory as the PDF.
- **Stuffs**: Notes, PDFs, summaries under `stuffs/`. Prefer extracting PDF text then working from `_extracted.txt`.
- **Capstone 26**: Faculty running notes in `Capstone 26/NOTES.md`. Append dated, tagged entries when dictated. Later: compile into reports (student initiative, sponsor coordination, follow-through). Do not rewrite old log entries.
